# セッション08：タイマ

## 目標

オンディレイ、オフディレイ、パルスタイマの違いを説明し、用途に応じて選べる。

## 解説

オンディレイは入力条件が成立してから設定時間後に出力する。オフディレイは入力条件が消えてから設定時間だけ出力を維持する。パルスは入力を契機に一定時間だけ出力する。時間設定の単位と、入力が途中で OFF になった場合の動作を必ず確認する。

## 演習

新規 `practice16` を作成し、オンディレイタイマを使って次を実装する。

- `X0` が ON のまま 3 秒経過したら `Y0` を ON にする。
- 3 秒より前に `X0` を OFF にしたら `Y0` は ON にしない。
- `X0` を OFF にしたら `Y0` を OFF にする。

| 操作 | 期待するタイマ状態 | 期待する `Y0` |
| --- | --- | --- |
| `X0` ON、1 秒 | 計時中 | OFF |
| `X0` ON、3 秒超過 | 完了 | ON |
| 計時中に `X0` OFF | リセット | OFF |
| `Y0` ON 後に `X0` OFF | リセット | OFF |

## 確認問題

1. 押してから遅れてモータを動かすとき、どのタイマを選ぶか。
2. 入力が OFF になってもランプをしばらく点灯させるとき、どのタイマを選ぶか。

## 完了条件

- 四つの操作で期待結果を確認し、使用したタイマ種別と設定時間を記録した。
