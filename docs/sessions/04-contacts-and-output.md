# セッション04：a/b 接点と単純出力

## 目標

a 接点と b 接点を論理値として理解し、単純な入出力ラダーを作成できる。

## 解説

a 接点は対象変数が TRUE のとき導通し、b 接点は FALSE のとき導通する。押しボタンの物理的な接点形式と、ラダー上の a/b 接点の記号を混同しない。ラダーの接点は、指定した変数の真偽を判定する要素である。

## 演習

1. `practice01` で、`X0` ON のときだけ `Y0` が ON になることを確認する。
2. `practice02` で、`X0` OFF のときに `Y0` が ON になることを確認する。
3. 次の真理値表を埋める。

| `X0` | a 接点を通るか | b 接点を通るか |
| --- | --- | --- |
| OFF |  |  |
| ON |  |  |

## 確認問題

1. `X0` が OFF のときに出力を ON にしたい場合、どの接点を使うか。
2. ラダー上の b 接点は、必ず現場の b 接点スイッチを意味するか。

## 完了条件

- `practice01` と `practice02` の出力条件を、真理値表で説明できる。
