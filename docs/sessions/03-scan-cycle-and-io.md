# セッション03：スキャン周期と I/O

## 目標

PLC が「入力読込 → プログラム実行 → 出力更新」を繰り返すことを説明できる。

## 解説

PLC はラダーを常に一段ずつ左から右、上から下へ実行しているわけではなく、一定の周期で繰り返し実行する。これをスキャンという。入力の短い変化はスキャン間隔より短いと取りこぼす可能性がある。出力や内部リレーを同じプログラム内で使う場合も、スキャンを意識する。

## 演習

1. `practice01` を動かし、`X0` を ON/OFF したときの `Y0` の変化を監視する。
2. `X0` をできるだけ短く操作し、変化を確認できたか記録する。
3. プロジェクト設定の周期タスクを確認し、設定値を記録する。
