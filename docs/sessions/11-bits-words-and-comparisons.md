# セッション11：ビット・ワード・比較

## 目標

BOOL と数値データを使い分け、設定値と実績値を比較できる。

## 解説

ビット（BOOL）は ON/OFF の一つの状態を表す。ワード型の数値は、カウント値、温度、設定値のような数を表す。数値制御では、変数の型、初期値、上限、リセット条件を明確にする。比較結果は BOOL となり、ラダー上の接点として使える。

## 演習

新規 `practice19` を作成する。

- `targetCount` を 5、`actualCount` を 0 から開始する。
- `X0` の一回のイベントで `actualCount` を一つ増やす。
- `actualCount >= targetCount` で `Y0` を ON にする。
- `X1` で `actualCount` を 0 に戻す。

| `actualCount` | `targetCount` | 期待する `Y0` |
| --- | --- | --- |
| 0 | 5 | OFF |
| 4 | 5 | OFF |
| 5 | 5 | ON |
| 6 | 5 | ON |

## 確認問題

1. 出力ON/OFFを表すのに適した型は何か。
2. 設定値と実績値を別の変数にする利点は何か。

## 完了条件

- 比較表の全条件を確認し、リセット後に実績値が 0 になることを監視した。
