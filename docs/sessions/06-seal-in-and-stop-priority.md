# セッション06：自己保持と停止優先

## 目標

起動・停止・自己保持を設計し、停止要求を優先する回路を作成できる。

## 解説

自己保持は、起動入力が OFF に戻っても出力自身の接点で回路を維持する方法である。通常は起動ボタンを出力接点と並列にし、停止条件を直列に置く。停止条件が成立したら保持経路も切れる位置に置くことが重要である。

## 演習

`practice10` を用いて次を確認する。

1. 起動入力を短く ON にしても、出力が保持される。
2. 停止入力を ON にすると、出力が OFF になる。
3. 停止入力が ON のままでは、起動しても出力は ON にならない。

| 操作 | 期待する `Y0` | 実測 | 判定 |
| --- | --- | --- | --- |
| 起動を一度押す | ON を保持 |  |  |
| 停止を押す | OFF |  |  |
| 停止中に起動を押す | OFF |  |  |

## 確認問題

1. 自己保持用の `Y0` 接点は、起動接点と直列か並列か。
2. 停止条件を保持経路の外に置くと、どのような不具合が起きるか。

## 完了条件

- 上表の三条件を満たし、停止優先の理由を説明できる。
