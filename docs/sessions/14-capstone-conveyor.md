# セッション14：総合演習：搬送コンベヤ

## 目標

要求から I/O 表、状態遷移図、ラダー、テスト記録を作成し、小規模な制御を完成させる。

## 要求

搬送コンベヤを次の条件で制御する。

- `X0`: 起動ボタン、`X1`: 停止ボタン、`X2`: 非常停止状態入力、`X3`: ワーク検出、`X4`: 満杯センサ
- `Y0`: モータ、`Y1`: 警報灯
- 起動条件が成立したときだけ `Y0` を自己保持する。
- `X1`、`X2`、または `X4` が成立したら `Y0` を停止する。
- `X3` を検出してから 3 秒以内に `X4` が成立しなければ `Y1` を ON にする。
- 同時に起動と停止を要求した場合は停止を優先する。

`X2` は教材上の状態入力であり、実機の非常停止安全回路を代替しない。

## 設計手順

1. I/O 表に変数名、用途、ON の意味を記入する。
2. 待機、運転、満杯停止、異常の状態遷移図を作る。
3. 停止条件、自己保持、警報タイマを別々にラダー化する。
4. オンライン監視でテスト表を埋める。

## テスト表

| ケース | 操作 | 期待する `Y0` | 期待する `Y1` | 判定 |
| --- | --- | --- | --- | --- |
| 通常起動 | `X0` を押す | ON を保持 | OFF |  |
| 通常停止 | `X1` を押す | OFF | OFF |  |
| 満杯停止 | 運転中に `X4` ON | OFF | OFF |  |
| 異常停止 | 運転中に `X2` ON | OFF | 要件どおり |  |
| タイムアウト | `X3` ON 後 3 秒、`X4` OFF | 要件どおり | ON |  |
| 競合 | `X0` と `X1` を同時操作 | OFF | OFF |  |

## 提出物と完了条件

- I/O 表
- 状態遷移図
- OpenPLC プロジェクト（`practice22`）
- 完成したテスト表
- オンライン監視で、各内部リレーと出力の状態を説明した記録
