# セッション02：OpenPLC Editor とシミュレータ

## 目標

OpenPLC Editor でプロジェクトを開き、コンパイル、ランタイムへのダウンロード、オンライン監視を行える。

## 準備

- OpenPLC Editor をインストールする。
- README の手順で OpenPLC Runtime を起動する。PC をターゲットにする場合は Docker 上の Runtime を利用する。
- 実機を接続しない。最初はシミュレータまたはローカル Runtime だけで実施する。

## 手順

1. `practice01` を OpenPLC Editor で開く。
2. デバイス設定でコンパイル専用を解除し、使用する Runtime に接続する。
3. プログラムをコンパイルしてダウンロードする。
4. `X0` を操作し、`Y0` の状態が変わることを監視画面で確認する。
5. 接続を切り、プロジェクトを保存せず閉じる。

## 演習

`X1` と `Y1`、`X2` と `Y2` についても同じ確認を行い、結果を記録する。

| 操作 | 期待する状態 | 実測 | 判定 |
| --- | --- | --- | --- |
| `X0` を ON | `Y0` が ON |  |  |
| `X1` を ON | `Y1` が ON |  |  |
| `X2` を ON | `Y2` が ON |  |  |

## 確認問題

1. 編集したラダーを Runtime で動かす前に必要な操作を二つ挙げる。
2. 画面上の接点が ON でも出力が変わらない場合、まず何を確認するか。

## 完了条件

- `practice01` を Runtime またはシミュレータで動かし、三つの入出力を確認した。
