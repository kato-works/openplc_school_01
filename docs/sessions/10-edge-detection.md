# セッション10：エッジ検出

## 目標

立上りエッジを使い、入力が OFF から ON へ変わった瞬間だけを一回のイベントとして扱える。

## 解説

PLC は入力が ON の間、何度もスキャンする。そのため、接点が ON であることを直接カウンタ入力にすると、長押しで複数回数える場合がある。立上りエッジ検出は前回 OFF・今回 ON の変化だけを TRUE にする。前回の状態を補助リレーで保持して作る方法もある。

## 演習

新規 `practice18` を作成する。

1. `X0` の立上りだけでカウンタを一つ増やす。
2. `X0` を 2 秒長押ししても、一回だけ増えることを確認する。
3. `X0` を OFF に戻して再度 ON にすると、もう一回だけ増えることを確認する。

| 操作 | 期待する増分 |
| --- | --- |
| `X0` を短く一回押す | +1 |
| `X0` を長押しする | +1 |
| OFF 後に再度押す | +1 |

## 確認問題

1. エッジ検出が必要になる理由は何か。
2. 立上りエッジとは、どの二つの状態の変化か。

- 長押しと短押しのどちらも一回として数えられる。
