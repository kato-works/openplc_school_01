# セッション13：オンライン監視と故障診断

## 目標

入力、接点、補助リレー、タイマ/カウンタ、出力の順に状態を追い、不具合を切り分けられる。

## 解説

「出力が動かない」原因は、入力が変化していない、ラダー条件が成立していない、インターロックが働いている、出力設定が違う、という順に切り分ける。推測だけでラダーを書き換えず、オンライン監視で各変数の実際の値を記録する。

## 演習

新規 `practice21` として、次の三つの故障ケースを用意または再現する。

| ケース | 症状 | 確認する順序 |
| --- | --- | --- |
| A | `X0` を操作しても `Y0` が動かない | `X0` → 条件接点 → `M0` → `Y0` |
| B | 起動できない | 停止/インターロック条件 → 起動条件 → 自己保持 |
| C | カウンタが進まない | `X0` の変化 → エッジ出力 → 現在値 → 完了出力 |

各ケースで、原因を一つだけ作り、次の形式で記録する。

| 症状 | 確認した値 | 原因 | 修正 | 修正後の結果 |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |

## 確認問題

1. 出力が動かないとき、最初に監視する変数は何か。
2. 推測で修正する前に記録すべきものは何か。

## 完了条件

- 三ケースについて、監視値、原因、修正、修正後の結果を記録した。
