# OpenPLC ラダー基礎カリキュラム

## 到達目標

この教材を終えた学習者は、OpenPLC Editor のシミュレータで基本的なラダーを作成し、入力・内部リレー・出力をオンライン監視して、基本的な不具合を切り分けられる。

対象は PLC 未経験者から初学者とする。実機の配線工事、メーカー固有命令、通信設定は扱わない。非常停止など人身・設備を保護する安全機能は、PLC プログラムだけに依存せず、実機では独立した安全回路で構成する。

## セッション一覧

各セッションは「解説 → OpenPLC 演習 → 確認問題」の順で進める。演習を開始する前に、入力の操作と期待する出力を表にしてからラダーを作成する。

各回の配布資料は [セッション資料一覧](sessions/README.md) から開ける。

| # | テーマ | 学習目標 | 演習・完了条件 |
| --- | --- | --- | --- |
| 01 | PLC と安全の基本 | PLC、入力、出力、センサ、アクチュエータの役割を説明できる | 制御対象の I/O を分類し、非常停止を PLC の通常停止回路と混同しない |
| 02 | Editor とシミュレータ | プロジェクト作成、コンパイル、ダウンロード、監視を行える | LED 出力を入力スイッチで操作し、監視画面で値を確認する |
| 03 | スキャン周期と I/O | 入力読込、演算、出力更新の順序を説明できる | 同一サイクルでの内部リレーと出力の変化を観察する |
| 04 | a/b 接点と単純出力 | a 接点・b 接点を論理値として使い分けられる | `practice01`、`practice02` を完成させ、入力ごとの出力を確認する |
| 05 | AND・OR・複合条件 | 直列・並列回路を真理値表から作成できる | `practice03`〜`practice09` を用い、各条件での出力を表に記録する |
| 06 | 自己保持と停止優先 | 起動、停止、自己保持の動作を説明できる | `practice10` を用い、停止入力で必ず出力が解除されることを確認する |
| 07 | 補助リレーとインターロック | 中間状態を補助リレーで表現し、競合動作を防げる | `practice11`〜`practice15` を用い、同時起動要求を許可しない回路を確認する |
| 08 | タイマ | オンディレイ、オフディレイ、パルスの用途を選べる | 起動入力から 3 秒後に出力する回路を作り、設定時間を変えて確認する |
| 09 | カウンタ | センサ入力を一回ずつ数え、リセットできる | 5 回の立上り入力で出力し、リセット入力でカウントと出力を初期化する |
| 10 | エッジ検出 | 押下中の入力を一回だけ数える理由を説明できる | 長押しでカウンタが一回だけ増えることを確認する |
| 11 | ビット・ワード・比較 | BOOL と数値データを目的別に使い分けられる | 設定値と実績値を比較し、実績値が設定値以上で完了出力を出す |
| 12 | 順序制御 | 状態を内部リレーで表して制御手順を設計できる | 待機→起動→動作→完了→待機の順で出力を遷移させる |
| 13 | オンライン監視と故障診断 | I/O、内部リレー、タイマを追って不具合を切り分けられる | 用意された「出力が動かない」ケースを、入力・論理・インターロックの順で診断する |
| 14 | 総合演習 | 要件から小規模なラダーを設計、実装、確認できる | 起動停止、異常停止、インターロック、タイマまたはカウンタを含む制御を完成させる |

## 新規演習の仕様

セッション 08 以降は、既存の BOOL 演習とは別に OpenPLC プロジェクトを追加する。プロジェクト名は `practice16` から連番にし、各プロジェクトには課題文、I/O 表、期待結果を `README.md` として置く。以下を追加時の受入仕様とする。

| プロジェクト | セッション | 最低限の I/O と合格条件 |
| --- | --- | --- |
| `practice16` | タイマ | `X0` を 3 秒継続で `Y0` を ON、`X0` OFF で `Y0` OFF |
| `practice17` | カウンタ | `X0` の立上りを 5 回数えて `Y0` ON、`X1` でリセット |
| `practice18` | エッジ検出 | `X0` を長押ししてもカウントは一回だけ増加 |
| `practice19` | ワード・比較 | 実績値が設定値以上で `Y0` ON、リセットで実績値を 0 に戻す |
| `practice20` | 順序制御 | 起動後に動作出力、完了入力で停止・待機へ復帰 |
| `practice21` | 故障診断 | 意図的な論理または I/O 設定の不備を監視で特定し、修正根拠を記録 |
| `practice22` | 総合演習 | I/O 表、状態遷移図、ラダー、テスト記録を提出 |

## 総合演習の題材

標準題材は「搬送コンベヤ制御」とする。起動ボタン、停止ボタン、非常停止状態入力、ワーク検出センサ、満杯センサ、モータ出力、警報出力を使う。学習者は I/O 表と状態遷移図を先に作成し、以下を確認する。

1. 起動条件を満たす場合だけモータが自己保持する。
2. 停止、非常停止状態、または満杯でモータが停止する。
3. ワーク検出から指定時間後に警報を出す、または指定数を数えたら停止する。
4. 同時の起動・停止要求でも停止が優先される。
5. オンライン監視で各状態を説明できる。
